# Godot 运行工程

启动与构建见[仓库 README](../../README.md)，玩法与数据规格见[开发规格](../../docs/README.md)。有效关卡从 `data` 注册（当前 34 张）；武将库、生产定义、命令与事件表在 `data/db`。本项目是非官方社区 MOD，许可与致谢见 [LICENSE](../../LICENSE) 与 [NOTICE](../../NOTICE.md)。

## 操作

左键点选/框选我军，`Shift` 加选；右键执行情境命令。命令面板为 3×3 九格，按队伍类型分型：

| 分型 | 九格内容 |
|---|---|
| 工人队伍 | 移动、攻击、运输 / 建造、修理、休息 / 解散、上船、（空） |
| 战斗队伍 | 移动、攻击、警戒 / 列阵、计谋、休息 / 解散、上船、单挑 |
| 运输船 | 第 9 格为下船（载员时可用） |

- 面板按钮是「先点按钮、再点地图目标」模型；`Esc` 取消待选。
- 热键 `Q W E / A S D / Z X C` 对应九格。
- 「组建」「加入」是面板旁补充按钮；独立工人须先组建队伍才能建造。
- 数字键 `1–9` 或左缘编号呼出编队：选中整队、主将排首位并把镜头定位到主将；`Ctrl + 数字` 编入；顶部「赤壁」、`M`、`Esc` 打开暂停菜单。
- 滚轮不缩放；边缘、中键拖动、方向键平移；`F11` / `F12` 截图；`Ctrl+F3` 调试信息；`P` 移至敌军附近。
- `Enter` 输入小写 `eternal` 切换秘籍，再按 `Enter` 关闭输入条；`F2–F9`、`[` / `]` 的说明见 [界面与秘籍](../../docs/12-interface.md#53-秘籍与隐藏键)。
- 存档槽：自动槽 + 手动 20 槽；读取可跨关卡。

完整规则见[界面](../../docs/12-interface.md)与[单位与武将](../../docs/07-units-officers.md)。

## 模块

| 模块 | 职责 |
|---|---|
| `menu.gd` | 主菜单、势力与关卡选择、存档槽 |
| `main.gd` | 战场装配、生命周期和兼容入口；领域规则在 simulation/battle |
| `app/` | 全局状态、场景服务、候选世界事务、存档编排、原子写与用户目录 |
| `simulation/navigation/` | 双层 A*、占格、城门 |
| `simulation/systems/` | 经济、采集、施工、科技、AI、载员、弹体、计时、任务、音效 |
| `presentation/battle/` | 地形流、城门模块；components/ 按布局、命令、输入、相机和单位外观拆分 |
| `presentation/hud/` | HUD 度量、皮肤、九宫格边框、命令图标、光标、暂停菜单、存档槽 |
| `presentation/media/` | 视频与事件文本 |

分层与数据流见[技术架构](../../docs/14-architecture.md)。

## 数据与素材

- `data/*.json`：34 张地图与战役参数；`data/db/`：生产单位、武将、命令、光标、音频、事件、任务规则。
- `art/full/`：高清图集、头像、地形分块、UI 母版与光标；运行工程只引用高清素材。
- `media/`：BGM、音效、开场、事件、结局与过场。
- 字段与数值约定见[数据规格](../../docs/15-data-spec.md)；素材规范见[美术规格](../../docs/17-art.md)。

## 开发参数

`--` 之后可传：

| 参数 | 作用 |
|---|---|
| `--map=CHIBIC1` | 指定关卡 |
| `--simtest=<秒>` | 固定 tick 跑完并输出摘要 |
| `--noview` | 不创建任何渲染节点 |
| `--view` | 强制创建表现层 |
| `--selftest` | 断言式自检 |
| `--smoketest` | 加载后写冒烟结果并退出 |
| `--demo` | 计时演示（不作判据） |
| `--screenshot` | 截图 |
| `--no-intro` | 跳过开场视频 |

存档默认位于 `%LOCALAPPDATA%\ChibiRTS\saves\`，不可写时自动回退，实际路径打印在启动日志与保存提示中。

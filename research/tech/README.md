> 目标：`CB.EXE` SHA-256 `2db7cc102e6fde547ab05d77cfddabc2079f5bc9be9b6b59b17bf435c5798cb7`。  
> 依据：原版代码 + `DATA.EXP` / `COST.EXP` 既有提取；`docs/` 和重制实现只作差异对照。

## 0. 结论速览

原版生产/研究动作表 `FUN_00422330` 共 **23 个 case**：

- **17 项真正升级科技**：
  - 大本营 3 级
  - 弓术 3 级
  - 兵器 3 级
  - 甲胄 3 级
  - 投石车 2 级
  - 水军 3 项（快船/战船/装甲）
- **6 项钱庄出售操作**：卖木/铁/粮的 1000、5000 档；不是战斗科技。

研究：

- **200 tick** 完成（`FUN_0045ECD0` 在 `199 < counter` 时结算）；
- 完成后 `FUN_00422330` 写科技字段；
- 面板只开放下一等级，不能跳级；
- 同势力同一科技不能重复；同一建筑同一时间只一项；
- 取消退款 **75%**（`FUN_00420070`）；
- 不同建筑可并行。

> **注意**：`docs/05-production-tech.md` 的“23 项科技”实际包含 6 项出售；**真正的科技升级只有 17 项**。  
> 另外，原版提示写“**大本营升一级/二级/三级**”，内部 `DAT_004b8d29` 也是 1/2/3；docs 的“升二级/三级/四级”是显示等级偏移写法。

### 1.1 四档加成对应单位

`FUN_004255C0` / `FUN_00425800` / `FUN_00425B50` / `FUN_00425E40` 用同一套类型分档：

| 档 | 单位类型（十进制） |
|---:|---|
| 0 | 32 / 36 / 45 / 46 |
| 1 | 37 / 38 / 39 / 48 |
| 2 | 40 / 41 / 42 |
| 3 | 43 / 44 |

- 弓术只加 **攻击 B**；
- 兵器只加 **攻击 A**；
- 甲胄同时加 **防御 A 与 B**；
- 只取**当前等级**一档，不把多级数值相加；
- 武将使用独立武力/品级公式，不套普通兵种档位；
- 建筑/工人不参与普通攻防科技加成。

## 2. 大本营升级

### 2.1 等级与效果

`FUN_00422330` case 0/1/2：

```c
DAT_004b8d29 = 1/2/3;              // 大本营等级
DAT_004b8d0c = DAT_004b01c0/e0/200; // 普通单位最大 HP 加成
for (200 units)
    if (普通单位)
        HP += DAT_004b01c0;         // 当前 HP +400
```

- 原版提示/字段是 **升一级/二级/三级**；
- 当前提取的文档值是每级 **+400 当前 HP**；
- 最大 HP 通过 `FUN_004254D0` 加 `DAT_004b8d0c`；
- 新建单位也继承最大 HP 加成；
- 大本营等级同时决定生产档位：
  - 0：100
  - 1：100/200
  - 2：100/200/500
  - 3：100/200/500/1000

### 2.2 前置

`FUN_00426E40` case 0/1 的大本营面板：

| 目标 | 代码条件 | docs 名称 |
|---|---|---|
| 一级 | campaign gate >1；两个建筑/状态标志 ==100 | 木材场 + 武器库 |
| 二级 | campaign gate >2；两个建筑/状态标志 ==100 | 木材场 + 武器库 |
| 三级 | campaign gate >3；弓术 >1 且 兵器 >1 | 弓术/兵器二级 |

- `DAT_004b8cc0` 是关卡/战役门槛；docs 对应第 1–4 章门槛。
- 六个 `DAT_005af2xx` 标志是建筑/状态条件；具体名称见 docs，代码只判断 `==100`。

## 3. 研究生命周期

### 3.1 命令与动作

`FUN_00428A50` 将生产/研究按钮转成 `DAT_004b7efc`：

- `0x11` = 研究动作；
- `DAT_004b7f00` = 科技 case；
- `DAT_0045ECD0` 在 200 tick 后调用 `FUN_00422330`；
- 面板掩码由 `FUN_00426E40` 按当前等级生成。

### 3.2 顺序与重复

- 同一线逐级：
  - 弓术 1→2→3；
  - 兵器 1→2→3；
  - 甲胄 1→2→3；
  - 投石车 1→2；
  - 水军三条各自独立；
  - 大本营 1→2→3。
- 面板只显示下一等级；没有前置时按钮不开放。
- 同势力同科技不能重复完成；重复派发会被拒绝/幂等。
- 不同建筑可以并行研究；同一建筑同一时间只一项。
- 研究占用建筑 **200 tick**；取消退 75% 资源。

### 3.3 费用行

从 `COST.EXP` 的既有提取 `production.json`：

```text
行 3–5   弓术 1/2/3
行 6–8   兵器 1/2/3
行 9–11  甲胄 1/2/3
行 12–17 出售 6 项
行 18–19 投石车 1/2
行 20–22 水军 快船/战船/装甲
行 0–2   大本营 1/2/3（费用来自 docs/建筑表）
```

每行前四个数是金/木/铁/0，后四个是四档加成；大本营行不是普通四档加成表。

## 4. 科技对属性的应用

| 属性 | 函数 | 字段 |
|---|---|---|
| 攻击 A | `FUN_004255C0` | `DAT_004b8d10..13`（兵器） |
| 攻击 B | `FUN_00425800` | `DAT_004b8d14..17`（弓术） |
| 投石车攻击 B | `FUN_00425800` | `DAT_004b8d20`（投石车） |
| 快船/战船攻击 B | `FUN_00425800` | `DAT_004b8d21/22` |
| 防御 A | `FUN_00425B50` | `DAT_004b8d18..1b`（甲胄）；舰船 `8d23` |
| 防御 B | `FUN_00425E40` | `DAT_004b8d1c..1f`（甲胄）；舰船 `8d23/24` |

科技字段：

```text
DAT_004b8d29 = 大本营等级
DAT_004b8d2a = 弓术等级
DAT_004b8d2b = 兵器等级
DAT_004b8d2c = 甲胄等级
DAT_004b8d2d = 投石车等级
DAT_004b8d2e/f/30 = 快船/战船/装甲等级
```

- 科技完成写入的是**全势力共享**字段，不是单个单位。
- 现有单位和新单位都在属性计算时读取当前字段。
- 大本营是例外：升级时还会遍历既有单位加当前 HP，并更新最大 HP 加成。

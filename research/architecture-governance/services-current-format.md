# 服务读边界与单一存档协议

起点为用户要求先提交的 `0cf394e`。目标是关闭剩余 BattleAccess 服务与配置借用，并按新约束删除旧存档兼容；不承诺旧模拟摘要必须不变，但变动必须有原因与验证。

## 服务和配置

删除 visibility、clock、projectiles、fire_fields、player_commands、build_types、cmd_pending_data、task_events、terrain_changes 九类 getter。连同已退役的六类集合/导航入口，十五类字面量属性、get/index 和 getter 重建都有门禁，清单 schemaVersion 为 4。

visibility_view 返回冻结的身份/修订键、尺寸和不可变字节字符串；只在修订变化时编码。渲染器自己解码并拥有 Packed 缓冲和图像，小地图/动画只读可见标记或标量查询，不保存模拟可见性对象。时钟返回冻结速度、标签和周期；建造选项按世界和内容签名复制/冻结。事件、地形改为计数、ID 和布尔查询，不再暴露容器。

弹体/火场读取有界表中参与显示的标量，未变化帧复用冻结投影；手动 service.step() 不推进 sim_tick 也会失效。缓存只保留标量身份和只读值，不保留服务、世界、源字典。相同数值/修订的替换世界仍按实际身份失效。

排队/泵送走会话命令端口，前端不能直接清空队列。执行动作再检查提交时的世界身份；回滚恢复的原世界动作仍有效，成功交换后旧 epoch 拒绝执行。单位指令继续携带 UID 与世界身份。

## 单一 v9

格式由 SaveFormat.VERSION 单独定义，只接受 v9 和校验正确的当前记录；v1–v8、无 checksum、旧规则指纹别名、旧地图内容转换和旧目录迁移全部拒绝，不尝试修补。旧恢复器、旧地图播种器、兼容目录 JSON 及 UID 侧文件删除，状态计时/载员不再传版本参数。

删除无建筑引用的 tech_progress 单项研究槽及其推进/取消/显示分支，仅保留 research_jobs。移除旧秒制计时、隐藏标记与即时混乱转换、旧撤退结构转换和单位跟随燃烧。原生后端相应移除死分支，以锁定依赖重建 DLL，声明哈希与源码签名同步更新；火场仍使用当前独立表。

字段完整性和默认值由 Schema 统一。非法 null、缺少必需标量、未知字段、派生格缓存、画布外位置、超长路径和非法游标拒绝。writer 的路径规范化处理当前执行器自身的结束瞬态，reader 不再修复历史非法游标。保存的内容指纹来自已经准备好的只读世界定义，不重新解析磁盘地图或修改全局规则。

库存存在性本身具有业务含义：普通建筑缺少 stock，与 stock=0 的资源建筑不同。因此 Schema 显式登记 stock/stock_max 为可选能力，保留存在性；其余持久字段写出完整默认值。无重寻路进度与进度 0 的摘要含义相同，避免仅因字段存在性改变读写摘要。

## 回归发现与修复

雾改用自有字节缓冲后，headless dummy renderer 的 ImageTexture.update() 不保留 CPU 取图像素。测试纹理现在在遮罩变化时重建；真实渲染仍使用原有 GPU 上传路径。实际像素回归验证可见、已探索和未知三种状态。

全量默认值最初使普通建筑获得 stock=0，改变建筑帧和续跑；读写/原生对照捕获该问题，改为 Schema 的显式可选库存后修复。计时 fixture 曾依赖旧迁移顺带重置阶段，现明确初始化休息计数。旧格式正向断言改为拒绝断言，当前格式的真实读写、续跑、载员、AI、Schema 和脚本/原生对照继续保留，不能用刷新摘要代替修复。

## 范围与证据

新增 test_context_read_models，覆盖递归冻结、缓冲隔离、暂停复用、手动效果失效、世界交换与回滚、相同逻辑修订的身份失效、旧排队动作拒绝和旧服务释放。test_current_format 替代迁移正向夹具，验证 v9、所有退役版本、规则/地图身份和 checksum。

历史阶段报告保留原样。最终用例集合、失败原始记录、复测关系、源码/原生二进制/Harness/日志哈希与模拟基线结果见配套验收文件。测试预算不因功能删除而放宽。微观读模型测试不替代正式包/GPU/完整战场性能验收。

最终本机验收：31 项静态门禁、28 项 release、75 项 development、9 项存档覆盖、CI 5 项、34 张地图启动、3 项自检、2 项模拟基线、31 项失效保护和 9 项表现故障场景全部通过。原生后端的源码签名、DLL 哈希及 627 个版本化运行资源的声明校验通过。两项最终夹具问题（静态方法反射写法、临时套件的旧成功文本）修正后独立复测，原始记录保留。

本阶段没有要求旧模拟参考值必须不变；实际测量与现有两项参考均一致，因此未改动基线文件。读写一致性问题先修复再测量，没有用重写摘要掩盖状态差异。当前新增实现保留在工作区，起点提交 `0cf394e` 可独立检出复审。

仍存在的其他 P2 包括宽状态与应用构造协议、规则加载 I/O、暂停/输入、发布证据和导出边界。本阶段没有把静态清单当作完整语法树证明；别名和部分旧命令返回的对象仍需人工审查。保留的 legacy_layout 是仍使用的 HUD 模式，不是存档迁移。

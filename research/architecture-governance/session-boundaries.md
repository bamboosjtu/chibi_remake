## 生命周期约束

暂停不再保存 previous_pause 布尔值。关闭一个模态只释放其自身令牌；乱序关闭、媒体取消或另一场景退出都不能取消仍活跃的暂停。结算倒计时在其令牌不是顶层时停止，切换失败保留结算模态。跨图候选失败只释放候选节点，成功释放旧场景范围；普通世界交换不释放场景拥有的菜单和简报。

暂停所有者使用 WeakRef，并在释放时撤销退出回调，重复打开不累积连接。严格属性代理可能拦截内建 signal 的属性访问，因此使用原生 connect/is_connected/disconnect 连接退出信号；实际战场根节点已加入回归。

保存投影和 tick 对运输汇总复用同一计算，保存不通过修复当前世界获得合法输出。活体原记录可以暂时含有未更新的派生汇总，序列化根据权威载员关系构造规范值，不修改这些记录；现有格式、规则目录和模拟基线不因此更改。

清理预加载前同时检查外部消费者。Game.Store、场景 CombatRules/UnitFootprint 等仍有真实消费者的入口保留；四个控制器及本轮触及模块中移除十二个确认没有消费者的导入。

## 门禁与回归

- 架构门禁新增：暂停写入只允许 PauseStack；应用控制器不恢复无效状态参数；存档管线不调用 transports.reconcile；CampaignSession 不直接读地图文件。
- 关卡索引生成和负例作为独立轻量检查。用例覆盖地图类型、重复/缺失战役条目与源数据不变。
- 暂停回归覆盖独立令牌、乱序释放、节点释放、重复连接、菜单/简报嵌套、媒体取消、世界回滚/交换和场景销毁。
- 应用边界回归覆盖索引单次读取与隔离、场景切换失败/成功、错误信息保留、路径规范化以及只读规范载员快照。
- 启动夹具覆盖缺失/错误索引；便携启动用独立进程和存档命名空间验证非法根拒绝及合法绝对目录。
- 托管 CPU 用例验证暂停状态机；本地有视图主套件验证实际模态与世界事务，不用单元标记冒充 UI 验收。

执行结果与源码指纹记录在 `session-boundaries-acceptance.json`。初次完整回归中的媒体失败定位为战场根节点的 signal 属性代理；修复后保留原失败和针对性重跑记录。

较重的串行回归也记录了运输/科技超时与索引性能波动。索引用相同引擎顺序比较检查点和当前工作区：800 单位分别约 55.32 ms / 54.75 ms，均低于原 100 ms 门槛；不删除最初的失败记录。运输核心交互与十一图覆盖拆为两个入口，共用同一份夹具与地图断言，分别使用 90/100 秒预算，合计仍为原 190 秒；每张地图都有独立 PASS 标记。大型用例固定串行，功能和性能门槛不靠增加超时或放宽断言通过。

端口层与宽 BattleState 仍需按真实使用关系逐步治理，new(world)/new(state) 的不同职责没有强行统一。InputMap、手柄与 HUD 原生命中/焦点迁移尚未实施。正式导出、签名、launcher 编译、标准完整战场和 GPU/发行包性能验收仍是独立工作；本轮本机回归不替代这些验收。

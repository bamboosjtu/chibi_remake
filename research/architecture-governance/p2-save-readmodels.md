# 存档边界与读模型治理

起点为已提交的 `779894d`。该提交保存上一阶段 P1 工作；此后的工作集中于评审 §3.3 和 §3.2，不改动模拟更新频率、平衡目录或确定性参考值。

## 存档准入和兼容

Schema 将 A/B 改为不落盘的派生缓存；旧缓存类型仍检查，恢复按位置重算。整数类型先检查有符号 32 位范围再转换，RNG 状态使用单独的有符号 64 位字符串规则。SnapshotSemantics 统一坐标、路径长度、时钟和任务集合的检查。

| 边界 | 策略 |
|---|---|
| 地图位置 | 单位锚点、路径、repath、施工入口和 spent 原位置限制在画布加一格 tileW 内；边缘内的画布外点恢复时夹回画布，超出拒绝 |
| 路径/游标 | 最多 rows×cols+2 个点；负值、分数和溢出游标拒绝；旧空路径非零游标或越过末尾的游标统一变为空路径/0 |
| 对象引用 | 强工作引用要求存在；攻击/加入/采集目标的清理窗口继续接收，恢复为 null/-1；攻击者与动作时钟 UID 作为历史标记保留 |
| 任务集合 | 各 4096 项，总计 32768 值节点，深度 8；事件 ID、可选 tick 与扩展字段分别检查 |
| 文件解析 | 32 MiB、容器深度 64，在 JSON 解析前执行；字符串中的括号和转义不参与结构计数 |
| 费用 | 共用 ResourceCost，允许四资源的稀疏字典，拒绝未知键和非法数值 |

v1–v3 的合法数字布尔值继续支持；v4–v8 的缺省及清理窗口有逐版本测试。保存和恢复共用游标规范化规则，恢复不修改调用方快照。生产费用、AI 资源池与旧研究费用改为世界自己拥有，防止读档后修改输入字典改变当前资源或退款。

文件校验与地图/规则校验保持分层。文件有效不等同于可在当前安装地图和规则中恢复；候选仍检查后者。未声称完成全部未知扩展字段、所有归属/编组关系或跨关卡切场景事务的治理。

## 备份来源

JsonStore/SaveRepository 增加 `{data, source}` 结果，保留原返回 payload 的接口。SlotCatalog 明确注入该结果读取器，元数据包含 primary/backup/none。缓存签名增加内容 SHA-256，避免同大小、同修改时间损坏后仍显示旧来源；超限文件只做大小判断，不读取全文哈希。

槽位标题、选中状态和实际读取后的反馈均显示使用备份，SaveService 保存本次实际来源。测试在相同秒级修改时间及相同文件长度下破坏主记录，验证无需人工清缓存即可显示和读取备份。

## 单位和选择投影

移除 BattleAccess 的 units、selected、map_data、nav、trainings 借用，连同此前已移除的 decor_cells，六类字面量入口为零。迁移覆盖 selection_info、command_model、command_art、unit_visuals、小地图、HUD、地形门洞、弹体导航和软件指针。

模型按用途划分：轻量全体名册、选择显示值、可见单位的渲染值、tick 边界运动采样、生产/工作摘要、悬停及指针布尔值。选择记录不携带路径、目标或单位字典；全体名册不携带整套动画字段；渲染数据按可见 UID 懒构建。缓存仅保存标量索引、只读记录和独立冻结的静态 clip 元数据，不保存源单位、世界或导航。

单位缓存键包含世界和导航身份、几何修订、tick、成员数及视觉事件失效；选择另比较实际显示标量，包括武将 tier。只读普通数组供边界返回，Packed 绘制缓冲由视图自己建立。持续渲染复用值，既不逐帧深拷贝整个世界，也不重新遍历已冻结 clip 子树。

取消生产/施工的按钮捕获 UID、世界身份和动作种类，不绑定源单位。应用层在入队和执行时检查 epoch，再解析当前实体；相同 UID 的替换世界不会被旧按钮取消工作。保持稳定 BattleAccess 节点，世界交换、失败回滚及保留投影后释放旧世界均有回归。

存档编排不再直接写精灵、血条和视图私有集合，改用 attach_loaded_world、finish_loaded_world、apply_loaded_unit。应用媒体组合与其他表现依赖不在此处一并重写。

## 门禁、验证和剩余范围

整个 presentation 的六类属性/get/index 回退、恢复旧 getter、投影深拷贝整单位及存档流程访问私有视图字段均由门禁阻止。清单 schemaVersion 3 如实记录扫描范围；它不是完整语法树或接收者类型证明。

新增 test_save_boundaries、test_unit_read_models；前者也进入 CPU-only save 门禁。进程级负向工具新增读模型过期查询，并支持独立输出目录。完整验收集合、原始失败、修复后的复测、源码与 Harness/日志哈希见配套验收 JSON。

两处旧夹具按新契约更新：元数据测试显式注入来源读取器，继续检查不重复解析/验证；动画测试将待渲染弓手保持在当前单位表，避免要求渲染已脱离世界的对象。预算没有放宽。

本机最终结果：31 项静态门禁、27 项 release、75 项 development 全部通过；CPU-only save 的 9 项以完全相同脚本和参数包含在 release/串行运行中。另有 CI 5 项、34 张地图启动、3 项自检、2 项原始基线、23 项失效保护和 9 项缺图/地形故障检查通过。两次原始夹具失败与修正后的复测日志均保留。基线文件未改动，运行源码冻结哈希在验收生成时重新核对。

独占采样中，800 个名册项加 24 个可见单位、十次更新的 CPU 投影构造中位数为 11.186 ms、P95 为 16.688 ms；600 次不变帧读取未重建投影，静态 sprite/clip 数据只复制一次。计时不包含结构断言，也不等同于完整渲染帧耗时。

仍需后续治理的边界明确保留：build_types、cmd_pending_data、task_events、terrain_changes 等其他容器，clock、visibility、projectiles、fire_fields、player_commands 等服务能力，以及其他命令返回的对象。宽状态/构造协议、模拟 I/O、暂停输入、启动和发布工程等 P2 也未在本阶段宣称关闭。当前测量是 CPU 投影构造与缓存复用验证，不替代正式包、GPU 或完整战场实时验收。

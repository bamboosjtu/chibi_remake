# 原版《赤壁》鼠标光标：图形、状态机与素材

> 对象：`_work/iso/CB.EXE`（PE32/x86，SHA-256 `2db7cc102e6fde547ab05d77cfddabc2079f5bc9be9b6b59b17bf435c5798cb7`）
> 资源：`RES/MOUSE.LWC`、`RES/MOUSE.IDX`、`SET/MOUSE.EXP`
> 方法：REA（Ghidra provider）静态分析 + LWC 帧解码；**未运行原版**，没有做逐状态实机像素比对。
> 范围：只覆盖鼠标光标本身，不扩展玩法规则。
> 说明：`plan.md` 的“禁止新增逆向分析”约束针对玩法规则取证；本目录是用户 2026-10-27 明确指定的光标表现层专项，不用于推导玩法规则。

## 结论摘要

1. 原版**不使用 Windows 光标**：窗口创建后调用 `SetCursor(NULL)`，光标由游戏自己按帧绘到 DirectDraw 表面（`FUN_004481c0`，见 `docs/research/BINARY.md` 的 USER32 导入说明）。
2. 光标图只有 **3 张 LWC 帧**，被装进 **3 个光标对象（bank A/B/C）**：
   - **A**：`DAT_00519800`，10 行 × 4 列，单格 **54×35**，战场主光标；每行一个状态、每状态 4 帧动画。
   - **B**：`DAT_00519960`，8 行 × 1 列，单格 **24×24**，摄像机边缘滚动的 8 方向箭头。
   - **C**：`DAT_00519ac0`，1 行 × 4 列，单格 **54×32**，4 帧飘动的红旗（帅旗）光标。
3. 状态切换由两个全局量驱动：
   - `DAT_004833f4`：当前“光标模式”（命令激活时写入）；
   - `DAT_00482460`：当前活动光标对象（bank）。
   鼠标移动、拖拽状态变化或命令切换时，`FUN_00423c80` 按“是否在视口内 → 是否拖拽中 → 命中什么单位 → 当前命令模式”决定行号，再调用 `FUN_00402e00` 切行。
4. 只有 3 个命令带专属光标：**攻击**（行 1，命中目标时切 2/3）、**运输/采集**（行 4，悬停资源时切 5）、**加入/编组**（行 8，悬停可加入单位时切 9）。
5. 默认光标是 **红旗（帅旗）指针**（行 0，空地面/视口外）；悬停单位时变成 **手持简牍的手形**（行 6，选择光标）；行 8 是加入命令的基础红旗指针。攻击的绿色/红色护手分别对应友方/敌方（绿=不可攻击，红=可攻击）。
6. 动画节奏：主循环每 **32 ms** 调一次光标 tick，每 **5 个 tick** 前进一帧 → **160 ms/帧**，4 帧循环 **640 ms**。
7. 每个状态有独立热点：红旗指针在左上矛尖 `(1,3)`；剑/手/十字/框在中心 `(26,17)`；镰刀 `(24,19)`。8 方向箭头热点在指向屏幕边缘的那一端。

## 1. 资源格式与加载

`MOUSE.LWC` 是 8-bit 调色板索引位图库，`MOUSE.IDX` 是 3 个 uint32 偏移，`SET/MOUSE.EXP` 只有 3 个索引 `0 1 2`。

| 帧 | 偏移 | 尺寸 | 用途 |
|---:|---:|---|---|
| 0 | `0x0` | 216×350 | bank A：10×4 状态图集 |
| 1 | `0x12760` | 24×192 | bank B：8 方向箭头 |
| 2 | `0x13970` | 216×32 | bank C：红旗 4 帧 |

每帧头 16 字节（width/height + 8 字节保留），行按 4 字节对齐补足；解码器与 `tools/lib/lwc2png.mjs` 一致。

加载入口 **`FUN_00446d40`**（由 `FUN_00455090` 在读取 `CBGame.set` 后调用）：

- 依次把同一份 `res\mouse.lwc` / `res\mouse.idx` 的第 0/1/2 帧装进三个光标对象；
- 每次装载都给出“行数 + 每行列数 + 每行热点”三组参数：
  - A：10 行、每行 4 列、热点 10 对；
  - B：8 行、每行 1 列、热点 8 对；
  - C：1 行、每行 4 列、热点 1 对。
- 单元格尺寸不是存在文件里的，而是 `整图宽 / 最大列数`、`整图高 / 行数` 算出来的（`FUN_00402ad0`）。
- 装载时还会为每个光标建立一个 **2× 单格尺寸** 的 mix buffer（`Cannot create mix buffer for cursor!`），用于合成/擦除当前光标。

> 调色板：MOUSE.LWC 只有索引。`CBGame.set` 在启动时加载 `res\score.pal`（代码里的 “Main Palette”，`DAT_00519768`）和 `res\arrow_t.pal`（“Palette”，`DAT_005197b0`）。**bank A 主预览用 SCORE.PAL**：它能把剑的绿色/红色护手正确还原（绿=友方、红=敌方）；`ARROW_T.PAL` 会把同一批像素整体变成米棕色，`BATTLE.PAL` 与 SCORE 接近（见三张 `mouse_states_sheet*.png`）。**bank C 主预览用 ARROW_T**（菜单/离开战场路径使用的 “Palette”），因为同一帧在 SCORE 下会变成白色旗。**CB.EXE 内没有 `battle.pal` 字符串，各画面实际使用哪套调色板没有截屏确认**，这是本研究的已知空缺。

## 2. 光标对象与绘制管线

`FUN_00402990` 构造光标对象，关键字段：

| 偏移 | 含义 |
|---:|---|
| `+0x60` | 可见/启用 |
| `+0x64` | 重绘开关（AVI 播放时置 0） |
| `+0x6c/+0x70` | 单帧宽/高 |
| `+0x74/+0x78` | 当前屏幕坐标（`GetCursorPos`） |
| `+0x7c` | `ClipCursor` 裁剪矩形 |
| `+0x8c` | 当前状态行 |
| `+0x90` | 上一状态行 |
| `+0x94` | 当前动画列 |
| `+0x98` | 上一动画列 |
| `+0x9c` | 每帧持续 tick 数（构造时 = 5） |
| `+0xa0` | 每行热点 (x,y) |
| `+0x120` | 每行动画帧数 |

绘制流程（`FUN_00402e40` + `FUN_00402ea0` + `FUN_00403110`）：

```
GetCursorPos
  → 光标矩形 = 鼠标位置 - 热点[row]，尺寸 = 单格
  → 恢复旧位置背景
  → 从图集取 (row, col) 单格，按调色板索引 blit（色键 0 透明）到 mix buffer
  → 裁剪到视口/窗口后贴回屏幕
```

拖拽开始时用 `ClipCursor` 把系统指针限制在战场矩形（`FUN_00402d00`）；窗口创建时 `SetCursor(NULL)` 隐藏系统光标。因此这是完整的“软件光标”，不是 `SetCursor(HCURSOR)` 换图。

## 3. 状态机（重点）

### 3.1 两个入口

- **`FUN_00423c20(row, refresh)`**：命令激活时直接设行并把 `DAT_004833f4 = row`；`refresh=1` 时不做命中测试（用于进战场/读档后的预置）。
- **`FUN_00423c80(x, y)`**：鼠标移动、拖拽更新或命令切换时刷新。顺序：
  1. `DAT_004833f8 == 0` → 直接返回（方向箭头滚动期间冻结）。
  2. 光标在视口矩形 `DAT_00482ff0..DAT_00482ffc` 外 → 行 0。
  3. `DAT_00483400 != 0`（拖拽中）→ 行 7。
  4. 命中测试 `FUN_00423260(x, y, ..., 0)` 取光标下单位；返回 0 = 没有单位，直接走 fallback（行号 = `DAT_004833f4`）。
  5. 有单位时按 `DAT_004833f4` 分支：
     - `0` 默认 → 行 6（选择光标），空地面时保持行 0；
     - `1` 攻击 → 命中单位时按 `FUN_004250f0(本方, 目标所属)` 切行 2/3，否则保持 1；
     - `4` 运输 → 命中资源类型 0x16/0x18/0x19 时切行 5，否则保持 4；
     - `8` 加入 → 命中本方且能解析队长时切行 9，否则保持 8；
     - 其它值 → 回到 `DAT_004833f4` 本身。
  6. 行号变化时 `FUN_00402e00`：旧行存入 `+0x90`，新行写入 `+0x8c`，动画列归零。

| 行 | 图形（SCORE.PAL 主预览） | 帧 | 热点 | 进入条件 |

| 1 | 交叉双剑，金色护手 | 4 | (26,17) | 攻击命令激活，未命中变体 |
| 2 | 交叉双剑，**绿色**护手 | 4 | (26,17) | 攻击模式下 `FUN_004250f0` 为真（同阵营或关系表 0/1）→ 友方，不可攻击 |
| 3 | 交叉双剑，**红色**护手 | 4 | (26,17) | 攻击模式下上述判定为假 → 敌方，可攻击 |

### 3.3 命令 → 光标

命令面板消息 `0x3f03/0x3f0a/0x3f11`（`FUN_00428a50`）：

| 命令 ID | 模式 | 光标行 | 含义 |
|---|---|---:|---|
| `0x3f03` | 1 | 1 | 攻击 |
| `0x3f0a` | 7 | 4 | 运输/采集 |
| `0x3f11` | 0x0F | 8 | 加入/编组（`FUN_0045d8d0` 内有 `RUN_GroupAdd_Warning...`） |

> `0x3f11` 的面板中文名没有从资源里直接解出；“加入/编组”是按模式 0xF 的处理器与自方单位判定推断的。

## 4. 边缘滚动（bank B）

`FUN_0041ca90` 每帧读取 `GetCursorPos`：

- 客户区 640×480，四边判定：`x==0`、`x==0x27f`、`y==0`、`y==0x1df`，组合出 8 个方向（0=NW, 1=N, 2=NE, 3=E, 4=SE, 5=S, 6=SW, 7=W）。
- 在边缘：切换到 `DAT_00519960`（bank B），行号 = 方向号，并推进摄像机滚动。
- 摄像机被地图边界顶住 / 鼠标离开边缘：切回 `DAT_00519800`（bank A），行号复位。
- 方向箭头显示期间 `FUN_00423ed0(0)` 关闭普通状态刷新，回来时 `FUN_00423ed0(1)` 打开。

8 个箭头各 1 帧，热点在指向边缘的那一端，例如 N `(10,0)`、E `(23,10)`、S `(13,23)`、W `(0,13)`。

## 5. 拖拽 / 框选（行 7）

- `FUN_00423900`：`DAT_00483400=1`，记录锚点与选择矩形，`FUN_00402d00` 用 `ClipCursor` 把光标限制在战场矩形。
- `FUN_00423a40`：鼠标移动时先刷新光标（行 7），再更新选择矩形端点；`FUN_00423b00` 用 `FrameRect` 画橡皮筋选择框。
- `FUN_004239a0`：`DAT_00483400=0`，恢复系统裁剪矩形，光标回到常规状态。

## 6. 光标切换与隐藏

- **切 bank**：`FUN_00403440(bank)` 把旧光标擦掉、行号归零、`DAT_00482460` 指向新对象。
- **离开战场**：`FUN_00409d70` 处理窗口消息 `0x4e21` 的 0 分支时释放战场资源，随后 `FUN_00403440(&DAT_00519ac0)` 切到红旗 bank C；进战场/初始化时切回 bank A。
- **AVI 播放**：`FUN_00447110` / `FUN_00447310` 把光标对象 `+0x64` 置 0，视频期间不重绘。

## 10. 对重制版的直接含义

- 正常地图指针是红旗/帅旗（热点在矛尖），不是 Windows 箭头；只有悬停到单位/物件时才换成手形。
- 攻击命令要有三态：未命中（金色双剑）→ 友方（绿）→ 敌方（红）；运输命令要有“空手/资源”两态；加入命令要有“红旗/可加入手形”两态。
- 热点不能用图片中心：红旗 `(1,3)`，镰刀 `(24,19)`，其余 `(26,17)`；否则点击位置会整体偏移。
- 每个状态 4 帧、160 ms/帧（640 ms 循环）；边缘箭头每方向 1 帧。
- 贴边滚动时指针替换为 8 方向箭头，且滚动期间冻结普通状态判定（`FUN_00423ed0(0)`）。
- 原图是 8-bit 调色板索引位图；直接按 RGB 重绘会丢失绿/红语义，若不复用索引需在重绘时显式保留“友方绿 / 敌方红”的约定。

## 11. 已知空缺

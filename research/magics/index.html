2. 火攻：单格 10 × 24

代码路径

FUN_0045F8B0 case 9
  FUN_00453A80(x, y, 100, 4, 1)
    effect type 7
    +0x28 = 10          // 伤害
    +0x64 = 4           // 伤害间隔
    +0x6e = 100         // 寿命
  FUN_00453060 case 7
    if (timer >= 4) { timer=0; FUN_00453D10(); }
    counter++; if (counter >= 100) end;
  • 单格，不是 1.5 格 AOE；
  • 固定 10 HP，不经过防御公式；
  • 不检查阵营，可烧友军；
  • 首击在第 5 次更新，最后一击第 97 次，共 24 次；
  • 最大 240 HP，不是 20 DPS × 6 秒。

3. 加速 / 减速

移动

  • 普通：每单位更新 1 步；
  • 加速：每更新 2 步，即 ×2；
  • 减速：只在奇数更新走 1 步，即 ×0.5；
  • 状态 2/3 互斥；800 更新；
  • 旧文档的“移动 ×1.5”不成立。

攻击

  • period = floor(1000 / rate)；
  • 加速：rate *= 2；
  • 减速：rate >>= 1；
  • 奇数 rate 时减速会截断，实际不是精确 0.5×；
  • 只确认攻击/动作；修理倍率未找到状态读取。

4. 远视：10 格覆盖

FUN_00426280(unit+0xC):
  if (*(char *)(unit + 0x64) == 1)  // 状态4
      return 10;
  return DATA.EXP v5;
  • 有效视野直接变为 10 格；
  • 不是基础视野 +10，而是覆盖；
  • 目标队伍成员都获得状态4；
  • 800 更新后恢复基础视野；
  • 揭雾：FUN_004583E0 / FUN_00457E60。

5. 状态计时：800 次单位更新

FUN_00443550 置 flag 并清零计时；FUN_0045B4E0 每单位更新把活跃状态计时 +1，799 < timer 时清除。800 是逻辑更新数，不是固定秒数。

6. 其余计谋要点

计谋原版行为与 docs/重制的差异
激励状态1；每 100 全局更新谋略 +5，上限 2×智+15；不直接加士气。docs 的“士气 +15”不成立。
混乱状态5；追加 0x1B 任务，队列轮到后才空转；不立即打断当前动作，不随机移动。docs 的“即时暂停并保留进度”过于简化。
滚木状态7；每 30 更新在施法者视野内取第一个敌人，武将士气 −50；无 HP 伤害；命中清状态。docs 的“2 格 40 伤害”完全不符。
埋伏状态6；仅步兵(32)/弓兵(45) 射程=视野（5/7），攻击固定 30；没有隐身。docs 的“不可索敌/不可选中”不成立。
恢复目标队伍主将 +50 HP，封顶；单体。docs 的 +50 正确，但不要做成全队。

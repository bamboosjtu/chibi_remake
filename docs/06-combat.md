# 06 战斗

> 本章定义属性口径、伤害公式、攻击节拍、弹道、近战判定、箭楼与击杀结算。计谋与单挑见[计谋、阵法与单挑](08-abilities.md)；单位编制见[单位与武将](07-units-officers.md)。

## 1. 属性口径

每个单位类型有四组战斗属性与四项辅助属性：

| 属性 | 含义 |
|---|---|
| 攻击 A / 攻击 B | 近战口径 / 射击口径 |
| 防御 A / 防御 B | 对近战口径 / 对射击口径 |
| 射程 | 格；`range ≤ 1` 为近战，`range > 1` 为远程 |
| 视野 | 格；决定揭雾半径 |
| 速率 | 每次攻击动作的 tick 基数：`周期 = floor(1000 / 速率)` |
| HP | 基础生命 |

**攻击口径选择**：攻击者类型属于下列集合时使用 B 口径（攻击 B / 防御 B），其余使用 A 口径：

```
18, 19, 33, 34, 39, 42, 44, 45, 46, 48, 49, 52
```

即箭楼、弓将、投石车、弓兵、水军与旗舰走射击口径；步兵、骑兵、工兵、武将本体（步/骑/文）走近战口径。

## 2. 伤害计算

### 2.1 普通单位

```
攻击 = 类型攻击 + 科技加成（按口径取 A 或 B）
防御 = 类型防御 + 科技加成（按口径取 A 或 B）
伤害 = max(1, 截断(攻击 − 防御))
```

### 2.2 武将单位

武将为队长的将本体（类型 29/31/33/35/52）：

```
攻击 = floor((武力 + 品级) × 类型攻击 ÷ 100)
防御 = floor(武力 × 类型防御 ÷ 100)
伤害 = max(1, 截断(攻击 − 防御))
```

- 品级由「等级 × 类型」查表得到，见[单位与武将](07-units-officers.md#3-武将)。
- 武将不套普通兵种的科技加成。

### 2.3 取整规则

- 武将的攻击、防御分别按 `research/exp_level` 的整数公式取整；升级不改变防御。
- 普通单位按类型与科技加成计算；最终伤害相减截断、至少为 1。

## 3. 攻击节拍

攻击使用已确认的整数动作时钟。修理仍共用该时钟，但其加减速影响是用户保留的重制暂定值，作为暂定规则：

```
周期 P = floor(1000 / 速率)
加速中：速率 × 2
减速中：速率 ÷ 2（整除）
```

| 阶段 | 规则 |
|---|---|
| 命令首 tick | 只初始化计数 1 与相位 0，不推进、不击发 |
| 等待 | 每 tick 计数 +1，达到 P 后进入相位推进 |
| 相位 | 达到 P 后每 tick 推进一相位 |
| 击发 | 相位等于 2 时结算一次 |
| 建筑（箭楼） | 跳过相位限制，达到 P 即击发 |

**时序示例**（速率 30，P = 33）：

| 动作行帧数 N | 首次击发 | 后续间隔 |
|---|---:|---:|
| N = 3 | 第 34 tick | 35 tick |
| N = 4 | 第 34 tick | 36 tick |
| N < 3 | 不击发 | — |

- 目标出射程时，本次击发重新等待同一目标；人工新命令立即清除旧计时。
- 切换目标或动作类型时重置计数与相位。
- 动画帧数 N 取该单位当前方向的动作行帧数。

## 4. 射程与移动

| 情况 | 规则 |
|---|---|
| 判定 | 双方脚点像素距离 ≤ 射程 × 44 |
| 近战补偿 | 近战单位在像素距离不足时，允许切比雪夫格距离 ≤ 2，但必须通过阻挡检查 |
| 超距 | 每 0.8 秒重算一次接近路径；近战走近目标占格边缘，远程走到目标本身 |
| 目标失效 | 目标死亡、淡出、上船或离开世界时取消攻击命令 |
| 建筑目标 | 箭楼在目标离开射程后取消命令，不追击 |

近战阻挡检查沿双方脚点连线逐点采样，遇到不可通行地形、封闭建筑或城墙即判定不可攻击；远程越墙不受此补偿限制。

## 5. 弹道与命中

| 项 | 箭 | 投石 |
|---|---|---|
| 发射者 | B 口径非投石单位 | 投石车 34 |
| 速度 | 16 世界像素 / tick | 8 世界像素 / tick |
| 起点 | 发射时攻击者脚点 | 同左 |
| 终点 | 发射时目标脚点 | 发射时目标所在格（格坐标） |
| 伤害 | 发射时记录完整伤害 | 发射时记录攻击 B 与落点格 |
| 命中目标 | 仍有效的锁定实体 | 落点格当前占用者（可命中友军） |
| 减伤 | 按目标当前防御 B | 按目标当前防御 B |
| 目标消失 | 不转移 | 按落点格当前占用者结算 |
| 射手阵亡 | 已发射弹体继续 | 同左 |

- 弹体从发射后的下一 tick 开始推进。
- 命中伤害在发射时确定，不因目标移动或期间科技变化重算；投石取落点格的当前占用者，仍使用发射时的攻击 B 与当前防御 B。
- 箭锁定发射时的目标 UID；目标消失或上船时该箭不伤害其他对象。投石以落点格为准，可命中之后进入该格的单位。
- 投石命中扬尘为纯表现，不追加范围伤害。
- 弹体池上限 100；满时丢弃本次弹体及其伤害，不等待、不替换、不重试。

## 6. 自动索敌

| 单位 | 行为 |
|---|---|
| 普通机动单位（含武将） | 空闲且可攻击时每 6 tick 分摊扫描最近敌军，范围为 min(8, 运行期视野) 格（运行期视野 = 表内视野 ×2）；将领及附近空闲成员共同接战 |
| 明确命令优先 | 行军、采集、施工、修理、运货、上船、休息和警戒不被自动接战覆盖；携带资源的空闲工人不丢货追敌 |
| 箭楼 18/19 | 已建成且空闲时，自动选择射程内最近的敌对**可攻击**目标 |
| 箭楼目标限制 | 玩家与 AI 的箭楼都只以人类玩家方为敌；不射击其他 AI 势力，不追击 |
| 运输船 | 无攻击能力，不能被选为目标派攻击方 |

## 7. 击杀结算

单位 HP 归零后进入死亡淡出：

| 项 | 规则 |
|---|---|
| 淡出 | 每 0.08 秒推进一帧死亡动画，结束后从世界移除 |
| 阻挡 | 尸体不再阻挡、不再被索敌、从选择中移除 |
| 武将 | 阵亡单位的武将身份解除，可重新组建；麾下存活成员解除编组 |
| 运输船 | 沉船时逐个销毁载员；不留悬空引用，读档不复活 |
| 击杀经验 | 击杀方所辖武将获得受害者类型的击杀经验 |
| 击杀士气 | 击杀方所辖武将士气 +受害者类型的士气值，被杀方所辖武将士气 −同值 |
| 大旗 | 大旗 26 被毁时，该方所有武将士气 −50 |

经验与士气写入所辖武将；被杀单位没有武将时只结算可归属的一方。

## 9. 士气与状态

- 士气初值 70，范围 0–100，显示在武将面板。
- 士气受击杀、激励计谋、任务效果与大旗被毁影响。
- 士气**不参与**伤害与行动判定，当前仅用于面板显示与任务效果。
- 六种计谋状态（激励、加速、减速、远视、混乱、埋伏）的时长与效果见[计谋、阵法与单挑](08-abilities.md)。

## 12. 验收要点

- 相同 tick 数与命令序列在不同速度、不同渲染帧率下结果一致。
- 速率 30、N=3 时首击第 34 tick、后续 35 tick；N=4 后续 36 tick。
- 近战不得隔墙/隔悬崖扣血；远程弹体不受遮挡补偿影响。
- 发射后目标移动不改变箭的锁定与伤害；投石以落点格为准。
- 弹体池满时本次攻击无伤害，且不影响既有弹体。
- 空闲普通单位不自动接敌；箭楼只打玩家方。

### 计谋特殊攻击

埋伏仅给32/45增加5/7格射程，effect8命中固定30HP，无视防御；不参与隐身或索敌过滤。火攻单格effect7固定10HP，可伤友军与建筑。两者不套普通攻防公式；节拍、目标与时长见08章和 research/magics。

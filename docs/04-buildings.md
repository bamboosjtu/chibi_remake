# 04 建筑与建造

> 本章定义建筑类型、占地、建造流程、工地施工、修理、出售与城门。生产与研究的建筑分工见[生产与科技](05-production-tech.md)。

## 3. 占地

占地由建筑类型决定，与图片宽高无关：

| 占格 | 建筑 |
|---|---|
| 3×3（9 格） | 帅帐、武器库、木材场、骑兵所、车兵所、船坞、铁矿、钱庄 |
| 2×2（4 格） | 粮仓、步兵所、弓兵所、城门、民居 |
| 1×1（1 格） | 箭楼、特殊、大旗 |

- 占地是等距平面上的正方形，投影为四条直边的菱形。
- 形状由锚点格与锚点 `B` 的奇偶共同决定，使用固定偏移表。
- 预览、选址碰撞、地图初始化与读档重建共用同一格集合，禁止按图片包围盒或交错坐标矩形截取。

## 4. 建造流程

### 4.1 发起

1. 选择一支**带工人的武将队伍**（武将本人或队内成员均可）；独立工人必须先组建队伍。
2. 在命令面板选择「建造」，选择建筑条目。
3. 在地图上选择落点；预览显示半透明建筑、地面占格与合法性（绿色可建、红色不可建）。
4. 左键确认落地。

发起者资格每次都要重新校验：队伍角色、存活、归属、成员上限。独立工人、无武将的队伍不能发起建造。

### 4.2 选址校验

落点必须同时满足：

| 校验 | 说明 |
|---|---|
| 建筑已开放 | 在玩家可建造清单内 |
| 实体上限 | 本方实体数 < 200 |
| 前置 | 对应前置建筑已建成 |
| 地形与占格 | 全部占格可通行、未被占用、未被其他单位占据 |
| 施工入口 | 至少一名随队工人能沿真实路径到达工地边缘 |
| 费用 | 四资源足够 |

任一不满足则拒绝，保留选址状态、不扣款；确认后不会把建筑自动挪到附近空地。

### 4.3 扣费与工地

- 确认后立即扣除全部费用，在锚点生成**工地**：HP = 0，占用整块占格。
- 随队工人自动接令，沿路径抵达工地边缘后进入工地；所辖武将也进入工地。
- 已下单的工地再次被右键，或用「运输」点击工地，可继续施工，**不重复扣费**。
- 选址时扣费成功但建筑生成失败，全额退款。

### 4.4 施工

| 项 | 规则 |
|---|---|
| 施工者 | 工地内的工人（类型 30），每人独立计时；平民 27/28 不能进入工地，只能修理 |
| 节拍 | 每 4 tick 结算一次 |
| 增量 | 每名工人每次 +2 HP，可叠加 |
| 完成 | HP 达到上限时转为已建成，移除工地标记 |
| 换帧 | 按 0、1/3、2/3、完成四个阈值切换；帅帐 0 为 9→8→1→0（阵营 1 缺少两帧，使用其最后可用施工帧） |
| 停工 | 工人失效、被阻断、离开或工地不可达时该工人不再提供施工 HP |

- 施工期间，工人与所辖武将隐藏在工地内，退出占格、索敌与选框；左侧队伍槽仍保留该队并可选中。
- 完工、取消、工地被毁或接到替换命令时，从入口附近合法空位退出；入口被堵则保留内部状态并重试。
- 多名工人共享同一工地：重新派走一名工人不销毁工地、不退款，其余工人继续施工。
- 完工时按建筑类型的击杀经验给所辖武将加经验并检查升级。

### 4.5 取消

- 取消工地按实际支付费用返还 75%，工地立即移除。
- 建筑建成后不能“取消”，只能被摧毁；摧毁不退款。

## 5. 修理

| 项 | 规则 |
|---|---|
| 执行者 | 工人或平民（27/28/30） |
| 目标 | 己方存活单位或已建成建筑；工地走「继续施工」而非修理 |
| 就位 | 沿路径到达目标交互距离内 |
| 节拍 | 与攻击共用整数动作时钟（`floor(1000/速率)`），每次结算后继续下一次 |
| 每次效果 | 目标 +16 HP（封顶），金/木/粮/铁各 −16 |
| 前置 | 四资源均不少于 16 |
| 结束 | 目标满血、失效、资源不足或目标归属变化 |

- 多名工人分别计时，每次结算重新检查资金与目标。
- 修理不改变大本营升级提供的生命加成上限。

## 6. 出售（钱庄）

钱庄 23 可执行 6 项资源出售：

| 项 | 获得金 | 支出 |
|---|---:|---|
| 卖木一千 | 500 | 木 1000 |
| 卖铁一千 | 800 | 铁 1000 |
| 卖粮一千 | 1000 | 粮 1000 |
| 卖木五千 | 2500 | 木 5000 |
| 卖铁五千 | 4000 | 铁 5000 |
| 卖粮五千 | 5000 | 粮 5000 |

- 占用钱庄 200 tick，同一时间只执行一项。
- 开始时扣除资源，完成时入账金；中途存读继续剩余时间。
- 显式取消返还 75% 资源；钱庄被毁则订单中止且不退款。
- 出售与生产、研究共用建筑工作锁。

## 7. 城门

城门（16/17）是带通行控制的建筑：

| 项 | 规则 |
|---|---|
| 通道 | 门洞格的可通行性由城门开闭状态决定 |
| 开启条件 | 归属方的机动单位位于门洞内，或位于城门椭圆感知范围内且其路径会经过该门 |
| 敌军 | 不能触发开启 |
| 友军优先 | 友军与敌军同时接近时优先开启 |
| 表现 | 开启显示第 1 帧并解除阻挡，关闭显示第 0 帧并阻挡 |
| 摧毁 | 释放通道并移除城门 |
| 重建 | 地图加载、读档后按实际位置重新计算开闭 |

- 友军寻路期间可临时规划穿越己方关闭的城门；行走提交仍校验实际开闭。
- 城门开闭变化会使路径失效并触发重寻路。

## 8. 建筑工作锁

每座建筑同一时间只执行**建造、生产、研究、出售**之一：

- 忙碌建筑不接收普通新工作；必须先显式取消（退款 75%）或等待完成。
- 不同建筑可并行工作；同势力同一研究项不能重复派发。
- 移动单位的新移动/攻击命令立即替换旧动作，不受建筑工作锁影响。

## 11. 验收要点

- 新建、读档、地图初始化的建筑占格集合完全一致。
- 工地从 0 HP 开始，每名工人每 4 tick +2 HP；完工后不再增加。
- 继续施工不二次扣费；取消按实际支付退 75%。
- 工地、敌方、已毁建筑不满足前置；不可达的工地不能施工。
- 城门开闭与通行、表现一致，敌军不能触发开启。

## 8. 民居交互与兼容

可见民居左键可选中，显示生命、归属和剩余金币；中立或敌方建筑不提供己方生产指令。工人运输命令可采集民居，战斗单位显式攻击或右键可摧毁中立民居。带工人的武将显式下达攻击令时，麾下工人同样接令并参与攻击；工人携带的资源不会被删除。命中使用建筑的完整世界包围盒，隐蔽目标仍不可选。

城门读档先恢复脚底格坐标再创建外观；门体与墙洞读取同一地图安装高度。此修复与窗口分辨率无关，普通墙体纹理和位置不变。已有存档的资源、工地已付费用和生产订单保留；新费用由独立定义覆盖，不改关卡内容版本。

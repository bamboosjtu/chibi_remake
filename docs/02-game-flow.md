# 02 游戏流程

> 本章定义从启动到退出单局的状态流转、时间模型与一帧内的执行顺序。具体系统规则见后续章节。

## 1. 状态流转

```
启动 → 主菜单 → 选择势力 → 选择关卡 ─┐
                └→ 读取进度 → 存档槽 ─┴→ 战场 → 胜负结算 → 暂停菜单 → 主菜单
```

| 状态 | 入口 | 出口 |
|---|---|---|
| 主菜单 | 启动、战斗结束返回 | 开始游戏、读取进度、退出 |
| 选择势力 | 主菜单「开始游戏」 | 确定进入关卡列表；取消回主菜单 |
| 选择关卡 | 选择势力后「确定」 | 点击关卡进入战场；返回回主菜单 |
| 存档槽列表 | 「读取进度」/ 暂停菜单「读取」「存储」 | 选定记录；取消回上一层 |
| 战场 | 关卡选择或读取进度 | 暂停菜单、关窗、胜负结算 |
| 胜负结算 | 战场胜负判定成立 | 胜利且存在下一关：5 秒倒计时自动进入下一关（可取消）；失败或终章：显示战役结束，可返回主菜单 |

## 2. 主菜单

| 菜单项 | 行为 |
|---|---|
| 开始游戏 | 打开「选择势力」：左曹操、右刘备；`←/→` 或 `A/D` 切换，`Enter` 确定，`Esc` 取消 |
| 读取进度 | 打开存档槽列表（无效记录置灰） |
| 对战模式 | 提示「暂未开放」 |
| 历史简介 | 播放 `media/videos/LISHI.AVI` |
| 退出游戏 | 退出进程 |

**关卡列表**：只显示所选战役线的关卡，按关卡编号排序，行文本为「第N章 关名」；滚轮或 `▲▼` 翻页，`Esc` 返回。所有关卡均可直接进入，无解锁顺序。

## 3. 关卡进入

进入 `main.tscn` 后按以下顺序初始化：

1. 读取 `data/<地图 ID>.json`；失败则显示可读错误页，不再进入战场。
2. 应用 `scenario` 段：玩家归属取第一个参战方，写入初始资源（金、粮、木、铁四元组）、任务号与开场片名。
3. 建立等距导航网格、水面层与探索遮罩。
4. 按 `objects` 生成地图对象（单位、建筑、资源点、布景）；按单位尾部字段生成武将与开局编队。
5. 建立索敌桶、占格索引与建筑占地；结算导航重叠。
6. 选定开局的第一支我方武将队伍，并占用控制组 1。
7. 建立 AI、存档服务与任务规则；若本次是读档，恢复快照（失败则回主菜单并保留原档）。
8. 建立 HUD、相机与输入；非读档且非测试模式时播放本关开场视频。

**开场视频**：`res://media/videos/<开场片名大写>.AVI`；播放期间模拟暂停，任意键或点击跳过；文件缺失时直接进入战场。

## 4. 单局循环

### 4.1 时间模型

| 项 | 规则 |
|---|---|
| 逻辑帧率 | 固定 30 tick/秒（`SIM_HZ = 30`，`SIM_DT = 1/30` 秒） |
| 速度档位 | 慢 100 ms、中 50 ms、快 30 ms、最快 20 ms；只改变 tick 投递周期 |
| 时间累积 | 按真实时间累加，单帧最多补 5 个 tick；欠帧留到下一帧，不丢弃 |
| 确定性 | 相同状态与命令序列在任意速度、任意渲染帧率下结算结果一致 |
| HUD 刷新 | 10 Hz，与模拟解耦 |
| 暂停 | 暂停菜单、视频播放、读档失败提示期间不推进模拟 |

暂停菜单「设置选项」可切换四档速度，默认「快」（30 ms）。

### 4.2 每个 tick 的执行顺序

| 序 | 步骤 | 说明 |
|---:|---|---|
| 1 | 更新视野 | 按玩家存活单位与建筑刷新探索/可见格 |
| 2 | 推进 tick 计数 | `sim_tick += 1` |
| 3 | 弹体推进 | 上一 tick 及更早发射的箭/石前进并结算命中 |
| 4 | AI 决策 | 各 AI 归属按节拍思考、下命令 |
| 5 | 生产推进 | 各建筑的生产订单推进，完成则出生单位 |
| 6 | 研究推进 | 各建筑的研究/出售订单推进，完成则生效 |
| 7 | 城门状态 | 按附近友军重算开闭 |
| 8 | 自动控制 | 托管标志生效，空闲战斗部队按 AI 节拍接敌 |
| 9 | 单位更新 | 死亡淡出、动作状态机、施工/采集/战斗/装载、外观同步 |
| 10 | 火场推进 | 单格火场按存在时长结算伤害与移除 |
| 11 | 工地与资源点换帧 | 工地按 HP、资源点按存量刷新显示帧 |
| 12 | 武将恢复 | 每 100 tick 结算体力/谋略恢复 |
| 13 | 载员汇总 | 重算运输船人数、载员兵力与装载标志 |
| 14 | 清理死亡 | 移除淡出完成的实体与失效引用 |
| 15 | 再次更新视野 | 反映本 tick 的位置变化 |
| 16 | 胜负判定 | 每 tick 检查脚本目标与歼灭/失败条件 |

### 4.3 操作与反馈

- 战场输入由 HUD 先消费；未被消费的输入交给战场（框选、点选、右键命令、相机平移）。
- 命令采用「先点面板、再点目标」模型：点击命令按钮后进入待选目标状态，用左键点地图目标生效；再次点击同一按钮取消，`Esc` 打开暂停菜单。
- 操作反馈显示在左下状态行，2.5 秒后消失。
- `F11` / `F12` 截图；`Ctrl+F3` 切换调试信息（默认关闭）；`M` 打开暂停菜单；`Enter` 打开信息输入，秘籍操作见[界面](12-interface.md#53-秘籍与隐藏键)。

## 5. 暂停菜单

| 项 | 行为 |
|---|---|
| 读取进度 | 打开存档槽列表；读取后恢复该记录（可跨关卡，切换场景） |
| 存储进度 | 打开存档槽列表；可覆盖选中记录或新建记录，可命名 |
| 战役任务 | 打开任务简报面板（与开场白同文） |
| 设置选项 | 选择游戏速度（慢/中/快/最快） |
| 系统帮助 | 状态行显示基础操作说明 |
| 结束战役 | 先保存到自动存档槽；保存失败则留在菜单并提示 |
| 返回游戏 | 关闭菜单、恢复模拟 |
| 不保存，返回主菜单 | 仅在保存失败后出现，放弃本次进度 |

关闭窗口等同于「结束战役」：先保存再退出；保存失败则保留战场并提示。

## 6. 胜负与结算

### 6.1 胜利

满足任一条件即胜利：

1. 关卡脚本目标达成（见[战役](11-campaign.md)）；
2. 所有敌对参战方的机动单位与建筑均被清空。

### 6.2 失败

同时满足以下两组条件：

- 金为 0，或我军机动单位为 0；
- 我军建筑为 0。

即：只要还有一栋建筑，破产或部队全灭都不会立即判负。

### 6.3 结算表现

- 屏幕显示「胜 利！」或「败 北……」，判定成立后模拟冻结，仅 HUD 与菜单继续响应。
- 胜利且存在下一关时弹出 5 秒倒计时，可点「留在战场」取消；自动进入下一关按战役关序，不跨战役。
- 失败、终章或无下一关时显示「战役结束」/「战役完成」，可返回主菜单；不播放结局视频，不写完成状态。

## 7. 存档触发点

| 场景 | 行为 |
|---|---|
| 暂停菜单「存储进度」 | 写入玩家选定的手动槽 |
| 暂停菜单「结束战役」 | 写入自动槽（槽 0）后返回主菜单 |
| 关闭窗口 | 写入自动槽后退出；失败则留在战场 |
| 主菜单 / 暂停菜单「读取进度」 | 读取选定槽；跨关卡时切换场景并在新场景内恢复 |
| 读档失败 | 保留原档、显示原因；从关卡进入时回主菜单 |

存档结构与槽位规则见[存档与兼容](16-save-compat.md)。

# 01 概述

> 本章说明项目定位、设计支柱与版本范围。具体规则见 03–11 章，技术实现见 14–19 章。

## 1. 产品定位

| 项 | 内容 |
|---|---|
| 类型 | 单机实时战略（RTS），无内政回合、无联网 |
| 视角 | 等距 2D 战场，固定缩放基准，可平移、可框选 |
| 题材 | 三国·赤壁；曹操线、刘备线双战役 |
| 形态 | 1997 年《三国赤壁》的非官方高清重制，社区 MOD，非商业 |
| 引擎 | Godot 4.7.2（GL Compatibility 渲染器），GDScript |
| 平台 | Windows x86_64 桌面 |
| 分辨率 | 默认 1920×1080，布局同时适配 1560×1440 与 640×480 基准 |

**核心体验**：在 34 张等距战场上，玩家以工人采集四类资源、建造营地与兵营、研究科技、组建武将与部队，通过移动、攻击、计谋与阵法击败敌方参战方，完成关卡目标。

## 2. 设计支柱

1. **可读的等距战场**：44 像素格距、三层地形、明确的占格与通行规则；单位和建筑在视觉上与其实际占地一致。
2. **以编制为核心的指挥**：战斗单位默认未编组；由武将带队形成“一将 + 最多 15 名成员”的队伍，命令面板按队伍类型分型，计谋与单挑由武将发起。
3. **有限资源与真实物流**：资源点有存量，工人必须走到资源边缘装载、走回仓库边缘卸货；资源不是被动收入。
4. **可预测的模拟**：固定 30 tick/秒的逻辑步长，相同初始状态、随机数状态与命令序列得到相同结果；存档保存完整模拟状态并可无损恢复。

## 3. 内容规模

| 内容 | 数量 |
|---|---|
| 战役线 | 2 条：曹操线 17 关（C1–C17）、刘备线 17 关（L1–L16，含 L7A/L7B） |
| 战场地图 | 34 张，全部可进入 |
| 参战方 | 73 个（含玩家方与 AI 方；部分关卡为三方） |
| 兵种/建筑类型 | 53 个类型定义（27 类建筑、26 类兵种；关卡实际实例化 44 个） |
| 武将 | 117 名，分属 4 个阵营块 |
| 科技 | 23 项（3 级大本营、3×3 普通研究、6 项资源出售、2 级投石车、3 项水军研究） |
| 计谋 / 阵法 | 9 种计谋、10 种阵法 |
| 媒体 | 13 首 BGM（2 首接入播放）、110 个音效、34 段关卡开场、10 段事件、3 段过场 |

## 4. 单局规则概览

| 项 | 规则 |
|---|---|
| 玩家归属 | 每关参战方列表的第一个；其余为 AI |
| 同时在场上限 | 每方 200 个实体，其中武将不超过 20 名 |
| 单队规模 | 1 名武将 + 最多 15 名成员（满编 16 个实体） |
| 初始资源 | 由关卡表给每方四元组：金、粮、木、铁 |
| 资源种类 | 金、粮、木、铁 |
| 胜利 | 达成关卡脚本目标，或清空所有敌对参战方的单位与建筑 |
| 失败 | （金为 0 或我军机动单位为 0）且我军建筑为 0 |
| 单局时长 | 无硬性上限；由资源节奏与关卡目标决定 |

## 5. 版本范围

**本版本提供**

- 34 张地图的完整单局：开局编成、采集运输、建造、生产、研究、编组、战斗、计谋、单挑、运输船装载与登陆、胜负结算。
- 双战役线的关卡选择（全部关卡可直接进入）与跨关卡存档读取。
- 12 类可建造建筑（含车兵所、船坞）、17 种兵种按大本营生产档位开放、23 项科技。
- 完整 HUD、命令面板、软件光标、键鼠操作、暂停菜单与设置。
- 存档槽（自动 1 个 + 手动 20 个）、存档命名、跨关卡读取。

**本版本不提供**

| 项 | 说明 |
|---|---|
| 对战模式 | 主菜单入口保留，点击提示暂未开放 |
| 历史简介 | 播放 `media/videos/LISHI.AVI` |
| 章节解锁 | 关卡列表全部可选，不设置章节锁；胜利后按战役关序推进，包含刘备 7a/7b |
| 战役终章 | 显示战役完成并可返回主菜单；尚未接入完整结局影片与完成状态持久化 |
| AI 计谋与阵法 | AI 不使用计谋、不变阵 |
| 计谋完整效果 | 火攻为单格地面火场，滚木扫描敌方主将并降低士气，埋伏为32/45特殊攻击；不含地面火蔓延与焦土变体 |
| 多人 / 联网 | 无 |

## 6. 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x86_64 |
| 运行时 | 导出包自带引擎，无需安装 Godot |
| 显示 | 窗口 1920×1080 起；支持 1560×1440；战场按视口自适应 |
| 输入 | 鼠标 + 键盘；无手柄 |
| 字体 | 内置 Noto Sans CJK SC（SIL OFL），不依赖系统字体 |
| 存档 | `%LOCALAPPDATA%\ChibiRTS\saves\`（不可写时依次回退，见 16 章） |
| 语言 | 简体中文 |

## 7. 产品结构

```
主菜单
├── 开始游戏 → 选择势力（曹操 / 刘备）→ 选择关卡 → 战斗
├── 读取进度 → 存档槽列表 → 战斗
├── 对战模式（未开放）
├── 历史简介 → 播放 LISHI.AVI
└── 退出游戏

战斗
├── 战场（地图、单位、建筑、资源、迷雾）
├── HUD（资源栏、编队条、命令面板、属性面板、小地图）
├── 暂停菜单（读取/存储/战役任务/设置/帮助/结束战役）
└── 事件与开场视频
```

# 赤壁之战 · 开发规格说明

《赤壁之战》是 1997 年《三国赤壁》的非官方高清重制版：单机实时战略（RTS）、等距 2D 战场、双战役线共 34 张地图。本目录是该项目的开发规格，面向策划、程序、美术、测试与发布维护者，描述**现行版本做什么、按什么规则做、由哪些模块实现、如何验收**。

## 文档约定

- **单一来源**：玩法数值以本规格与 `godot/chibi_remake/data/db/*.json` 为准；代码是实现，不是口径。实现与规格不一致时，修正代码或提交规格变更。
- **路径**：代码路径相对 `godot/chibi_remake/`；仓库路径相对仓库根目录。文档内链接均为相对路径。
- **数值单位**：时间以逻辑 tick 计（30 tick/秒）；射程、视野以格计；坐标为格坐标 `(A 行, B 列)`；像素仅用于渲染换算。
- **标识**：兵种、建筑、地形、命令使用稳定数字 ID；武将使用素材库全局索引（0 起）。区域矩形写作 `[A0..A1]×[B0..B1]`，闭区间。
- **不记录过程**：本文档只描述现行规格，不记录日期、轮次、评审编号与修复历史；变更由版本库历史承载。
- **范围声明**：每章「范围」小节说明本版本开放与不开放的内容，属于设计边界，不是完成度指标。

## 术语

| 术语 | 含义 |
|---|---|
| 归属（owner） | 阵营编号。0 为中立/布景，其余为参战方；每张地图第一个参战方是玩家 |
| 参战方（side） | 关卡表中的一方，含归属、难度初始化、初始资源、武将名单与档次 |
| 逻辑 tick | 固定模拟步长，1/30 秒；渲染帧率不影响结算 |
| 档次（rank） | 关卡表给武将的开局等级参数；等级 = 档次 − 1（档次 0 用默认值） |
| 品级（grade） | 由武将等级与类型查表得到的加成值，参与攻防与单挑 |
| 占格档 | 单位/建筑在地面占据的格数档：1、4、9、16 格 |
| 工地（site） | 已下单选址、尚未完工的建筑，从 0 HP 开始由工人施工 |
| 编组（group_officer） | 成员与武将的归属关系；一队武将 + 最多 15 名成员 |
| 控制组 | 数字键 1–9 对应的对象集合，存稳定 UID |
| 科技门槛 | 关卡表给每方的 1–4 档，决定可建造/可生产/可研究的范围 |
| 行为档位 | 关卡表给 AI 的 0/1/2 档，决定其训练、建造与科技策略 |
| 有效视野 | 单位当前视野；远视状态期间固定为 10 格 |
| 地图对象 | 关卡开始时按地图数据生成的单位/建筑/资源点，带 `map_index` |

## 自检

```powershell
node tools/docs_lint.mjs
```

检查内容：本地链接可达、规格区不含来源研究与日期化过程记录、附录小节与参战方数量完整。

修改规格时：

1. 同步受影响的章节、数值表与「实现对应」；
2. 关卡开局或名单变化后运行 `node tools/lib/openings.mjs` 重生成附录；
3. 运行 `node tools/docs_lint.mjs` 与 `node tools/test_opening_forces.mjs`。

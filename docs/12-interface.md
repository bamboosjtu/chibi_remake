# 12 界面

> 本章定义 HUD 布局、命令面板、软件光标、键鼠操作与菜单。存档槽对话框见[存档与兼容](16-save-compat.md)；媒体播放见[音频与媒体](13-audio-media.md)。

## 1. 布局基准

| 项 | 规则 |
|---|---|
| 逻辑基准 | 640 × 480；所有 HUD 元素按 `s` 等比放大 |
| 缩放系数 | `s = clamp(min(视口宽/640, 视口高/480), 0.5, 3.0)` |
| 默认窗口 | 1920 × 1080 |
| 已验证分辨率 | 1920 × 1080、1560 × 1440 |
| 战场矩形 | 顶栏、左条、右面板、底栏之外的区域；相机夹边、小地图取景与边缘滚屏共用 |
| 相机缩放 | 固定为布局系数，滚轮不改变缩放 |

## 2. HUD 区域

| 区域 | 内容 |
|---|---|
| 顶部通栏 | 资源栏（金、粮居左；木、铁居右）、中间「赤壁」红匾 |
| 左缘竖条 | 1–10 号编队/生产槽、功能钮 |
| 右侧面板 | 小地图、选中对象头像与名称、兵力牌、命令区、属性区 |
| 左下状态行 | 操作反馈、悬停信息（2.5 秒后消失） |
| 底部边条 | 画面装饰与边缘滚屏热区 |

### 2.1 资源栏

- 四格顺序固定：金、粮、木、铁。
- 每格显示图标与数值；数值为整数。
- 资源不足时生产/建造条目置灰，悬停显示费用与原因。

### 2.2 右侧面板

自上而下：

1. **小地图**：显示地形缩略、单位点、当前取景框；左键点击定位，按住拖动连续移动视角。
2. **选中框**：头像或单位图标、名称、官职/状态、血条。
3. **兵力牌**：所选队伍的代表单位、兵数或建筑状态。
4. **命令区**：9 格图标面板或文字命令列表（见 3 节），底部为翻页与返回按钮。
5. **属性区**：6 行数据（见 2.4）。

### 2.3 左缘槽位

- 10 个槽位；1–9 对应控制组，第 10 槽保留。
- 选中生产建筑时，1/2 号槽优先显示前两项生产，并显示费用提示。
- 工地队伍仍占用原槽位，显示「建」标记；点击或数字键可选中该队。
- 槽位指示灯：可用为绿，不可用为红。

### 2.4 属性行

| 选中对象 | 六行内容 |
|---|---|
| 武将队伍 | 武力、智力、经验、谋略、士气、兵数 |
| 普通单位 | 生命、攻击、防御、视野、人数/等级、携带 |
| 建筑 | 生命、状态、进度、工作、等级、视野 |
| 运输船 | 生命、状态、载员、载员兵力、视野、装卸 |

## 3. 命令面板

### 3.1 图标面板

- 3×3 固定格位，按选中对象分型（工人/战斗/运输船），内容见[单位与武将](07-units-officers.md#5-命令面板)。
- 快捷键 `Q W E / A S D / Z X C` 对应九格。
- 图标三态：常态、按下、悬停；不可用时置灰。
- 悬停显示「(热键) 名称」；点击按下播放点击音，松开命中才执行；按住移出即取消。

### 3.2 文字命令列表

选中建筑时使用文字列表（生产、研究、出售、取消）：

- 每页 6 项，`PageUp/PageDown` 或翻页按钮切换；
- 建筑忙碌时显示当前工作与整数进度；
- 只显示与当前工作对应的取消入口；
- 生产条目显示图标、人数/进度与费用。

### 3.3 子菜单

| 子菜单 | 条目 | 返回 |
|---|---|---|
| 计谋 | 9 项 | 返回按钮或 `Esc` |
| 列阵 | 10 项 | 返回按钮或 `Esc` |
| 建造 | 12 类建筑，分页 | 返回按钮或 `Esc` |

## 4. 软件光标

使用绘制的光标替代系统箭头：

| 状态 | 外观 | 触发 |
|---|---|---|
| 默认 | 红旗指针 | 空地面、战场外、暂停/菜单 |
| 单位悬停 | 手持简牍 | 默认模式下命中单位 |
| 攻击 | 交叉双剑 | 攻击待选 |
| 攻击/友方 | 绿色护手双剑 | 攻击待选且悬停友方 |
| 攻击/敌方 | 红色护手双剑 | 攻击待选且悬停敌方 |
| 运输 | 弯镰 | 运输待选 |
| 运输/资源 | 青绿描边弯镰 | 运输待选且悬停资源点 |
| 框选 | 四向箭头 | 拖拽框选中 |
| 加入 | 红旗指针 | 加入待选 |
| 加入/目标 | 手持方框 | 加入待选且悬停可加入单位 |
| 滚屏 | 八方向箭头 | 鼠标贴住客户区边缘且相机可移动 |

- 四帧循环，每帧 160 ms；状态切换从首帧开始。
- 框选时光标被限制在战场矩形内。
- 视频播放时隐藏光标；暂停菜单与普通界面显示默认红旗指针。
- 光标热点按状态逐行定义，避免点击位置偏移。

## 5. 键鼠操作

### 5.1 鼠标

| 操作 | 行为 |
|---|---|
| 左键点选 | 选中单位/建筑；`Shift` 加选 |
| 左键拖框 | 框选我方单位 |
| 左键点资源 | 选择中包含工人队将领时派出麾下采集；仅选成员时保留个体权限 |
| 左键点目标 | 有待选命令时落到目标上 |
| 右键 | 情境命令：攻击、采集、继续施工、移动（见 07 章） |
| 中键拖动 | 平移相机 |
| 鼠标贴边 | 八方向滚屏（带宽 = 布局系数像素） |
| 点击小地图 | 定位视角；按住拖动连续移动 |
| 点击「赤壁」匾 | 打开暂停菜单 |

### 5.2 键盘

| 按键 | 行为 |
|---|---|
| `Q W E / A S D / Z X C` | 命令面板九格 |
| `1–9` | 呼出编队；选中整队、主将排在首位，镜头定位主将（空编队不触发其他操作） |
| `Ctrl + 1–9` | 把当前选择编入该组 |
| `方向键` | 平移相机 |
| `PageUp / PageDown` | 命令列表翻页 |
| `Esc` | 关闭子菜单；否则打开暂停菜单 |
| `M` | 打开暂停菜单 |
| `F` | 视角归中 |
| `B` / `U` | 切换建筑/单位显示 |
| 生产 | 点击生产建筑面板中的生产按钮 |
| `Ctrl+F3` | 调试信息开关（默认关） |
| `F11` / `F12` | 截图 |
| `Enter` | 打开/关闭信息输入条 |
| `P` | 镜头移至敌军附近 |

- 滚轮不缩放。
- 视频播放中任意键或点击跳过。
- 输入先由 HUD 消费，未被消费的交给战场。

### 5.3 秘籍与隐藏键

战场按 `Enter` 打开信息输入条，输入小写 `eternal`，再按 `Enter` 关闭。识别到第五个字符 `n` 时立即切换秘籍开关，因此输入 `etern` 也可生效。逐字符大小写严格匹配，失配重置且不重试当前字符；再次输入可关闭秘籍。`Esc` 关闭输入条。输入条打开时屏蔽战场命令、鼠标操作及相机滚动，模拟继续运行。

| 按键（须开启秘籍） | 行为 |
|---|---|
| `F2` | 切换托管：每 41 tick 为空闲战斗部队下达攻击可见敌人的命令；保留工作、警戒和已有命令，不接管经济 |
| `F3` / `F4` | 当前选中的首个我方武将等级 −1 / +1，限制 0–9；经验不变并同步武将池 |
| `F5` | 显示界面/指针功能暂不提供的提示 |
| `F6` | 切换取消我方建筑前置；仍扣资源，并检查兵力上限、工人、地形、占地及可达性 |
| `F7` | 切换我方普通伤害免疫，含弹体、火场及旧档灼烧；不改变速度、施工或任务结算 |
| `F8` | 切换全图可见；关闭恢复实际迷雾，不把全图写入探索记忆 |
| `F9` | 金、木、粮、铁各加 10000，可重复 |
| `[` / `]` | 本战役上一关 / 下一关，使用章节顺序，不跨战役或循环 |

`F10` 不执行操作；`F11` 截图与 `P` 镜头跳转不要求秘籍开启。`F12` 保留为截图别名，调试信息使用 `Ctrl+F3`。

托管开关进入完整快照，旧档缺省关闭。秘籍开关、取消前置、免伤和全图可见属于本战场会话，同一战场读档保留，新战场默认关闭；信息输入条在成功读档后关闭，拒收坏档时保持原状。

## 6. 菜单

### 6.1 主菜单

| 项 | 行为 |
|---|---|
| 开始游戏 | 选择势力 → 选择关卡 |
| 读取进度 | 打开存档槽列表 |
| 对战模式 | 提示暂未开放 |
| 历史简介 | 播放 `media/videos/LISHI.AVI` |
| 退出游戏 | 退出 |

势力选择：左右两格立绘，红箭头与红框标出当前选择；`←/→` 或 `A/D` 切换，`Enter` 确定，`Esc` 取消。

关卡列表：木条行，显示「第N章 关名」；滚轮或 `▲▼` 翻页，`Esc` 返回。

### 6.2 暂停菜单

| 项 | 行为 |
|---|---|
| 读取进度 / 存储进度 | 打开存档槽列表 |
| 战役任务 | 打开任务简报面板 |
| 设置选项 | 四档速度（慢/中/快/最快） |
| 系统帮助 | 状态行显示操作说明 |
| 结束战役 | 保存到自动槽后返回主菜单 |
| 返回游戏 | 关闭菜单 |
| 不保存，返回主菜单 | 仅在保存失败后出现 |

### 6.3 存档槽对话框

| 项 | 规则 |
|---|---|
| 标题 | 「存 储 进 度」或「读 取 进 度」 |
| 列表 | 自动槽/旧版进度 + 记录 01–20；显示名称、关卡、时间 |
| 保存 | 可新建或覆盖选中记录；名称最长 40 字 |
| 读取 | 只有有效记录可读；损坏记录置灰 |
| 跨关卡 | 读取其他关卡时切换场景并恢复 |
| 失败 | 在对话框内提示，原记录保留 |

## 7. 字体与文案

- 界面字体：内置 Noto Sans CJK SC（SIL OFL），不依赖系统字体。
- 菜单标题与按钮：优先 KaiTi / STKaiti / Noto Serif CJK SC。
- 所有玩家可见文本为简体中文；错误提示给出原因与下一步操作。
- 状态行反馈 2.5 秒后自动清除。

## 9. 验收要点

- 1920×1080 与 1560×1440 下 HUD 不重叠、不越界，战场矩形与相机夹边一致。
- 命令面板分型正确：将本体工人 8 项、战斗 9 项；工人成员 3 项、战斗成员/未编组 4 项；运输船移动/下船 2 格。
- 光标状态与命令待选、目标关系、资源悬停一致；热点不偏移。
- 按键在 HUD 与战场之间不重复消费；`Esc` 优先关闭子菜单。
- 存档槽列表只允许读取有效记录，保存失败不覆盖原记录。

### 战役胜利后的推进

胜利文字下方显示下一章标题，5 秒后载入同一战役下一张地图；可立即点“下一关”，或点“留在战场”取消倒计时并保留推进按钮。新章按自身初始编制和资源开始，播放开场与任务，不把上一局存档当作下一局恢复。刘备顺序包含 7a→7b→8；两条战役终章不会串线。败北和终章提供返回主菜单。胜负确定后停止模拟推进，读入已经胜利的进度也恢复此界面。

队伍槽呼出单支部队时，主将与其成员共同选中也显示主将指令；计谋、列阵与单挑交由主将执行。仅选成员时保留成员面板，多支队伍或无关单位混选时保留混选规则。

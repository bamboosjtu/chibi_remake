> 覆盖 34 关：曹操线 C1–C17、刘备线 L1–L16（含 L7A/L7B）。
> 数据来源：`godot/chibi_remake/data/chibi*.json`（参战方、资源、名单、档次、部队与建筑）与 `data/db/officers.json`（从 0 开始的武将索引）；关卡的统辖编号从 1 开始。生成入口 `node tools/lib/openings.mjs`。
